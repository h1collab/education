# Zorix Education

Biblioteca didattica statica e interattiva in italiano per prima, seconda e terza media.

## Avvio rapido

Apri direttamente `index.html` in un browser.

## Termux / localhost

```bash
pkg install python
cd zorix-education
python -m http.server 8080
```

Poi visita `http://localhost:8080`. Il file `index.html` è l'indice generale.

## Contenuti

Quindici materie, 270 unità HTML indipendenti e 540 diagrammi SVG. Ogni unità
include teoria, esempi, errori frequenti, sfide casuali, missioni per studenti,
quiz, scaletta docente da 45 minuti, autoverifica e checklist.

## Pubblicazione statica

Carica tutti i file della cartella su GitHub Pages, Netlify, Vercel, Cloudflare Pages o qualsiasi hosting statico. Non sono richiesti build, dipendenze o variabili d'ambiente.
